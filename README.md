# Nylo Sell Scrap

A FiveM resource that allows players to sell scrap materials to an NPC for money.

## Features

- NPC located at a configurable position
- Configurable payout range for scrap items
- Easy to use interaction system
- Customizable NPC model and animation

## Configuration

The resource can be configured through the `config.lua` file:

- NPC location and appearance
- Sellable scrap items
- Payout ranges
- Interaction settings
- Custom text and notifications

## Installation

1. Place the resource in your server's resources folder
2. Add `ensure nylo-sell-scrap` to your server.cfg
3. Configure the settings in config.lua to your liking
4. Restart your server

## Dependencies

- No external dependencies required
